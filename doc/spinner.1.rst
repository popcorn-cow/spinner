NAME
====

Spinner - Spin your favorite political logos

SYNOPSIS
========

bin/spinner-release

DESCRIPTION
===========

Spinner is a work in progress toy application to spin images like those videos on twitter or something

BUILDING
========

1. clone the project from github
2. copy the config.def.h file and rename the copy config.def.h
3. start a terminal session with the root of the project as the current working directory
4. type in "make" for a debug build or "make RELEASE=1" for a optimized binary for giving to others
5. profit

BUGS
====
